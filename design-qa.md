## Проверка пяти визуальных поверхностей

| Поверхность | Результат |
| --- | --- |
| Композиция приглашения | Афиша, факты, блок компании, главный CTA и вторичные действия собраны в одну карточку с одинаковыми боковыми полями. Планы вынесены с главной на отдельный экран. |
| Цвет и типографика | Локальный Max Sans в Regular и Medium, цвета MAX и облегчённые подписи применены на ключевых экранах. |
| Иконки и действия | Самодельный знак молнии удалён. Факты внутри карточки имеют иконки; галочки и стрелки заменены едиными пиктограммами. Ссылки выглядят как действия. |
| Форма и поиск | Пресеты показывают точное время, последние направление открывает поиск по 12 занятиям, город выбирается в собственном списке. Индикатор поиска двигается только через CSS transform. |
| Адаптация и состояния | Проверены ширины 320, 360, 390, 430 и 1280 px, длинные заголовки событий и компаний, раскрытие подробностей, `NEAR`, поиск, сохранение и действия с местом, планы и состояния провайдера. |

## Отличия от статичного концепта

- Дата, цена, адрес, участники и статусы в работающем приложении берутся из API; примерные тексты концепта не подставляются.
- Кассета удалена; обе карточки используют одну спокойную геометрию в афише.
- У формы на небольших экранах блок еженедельного повторения доступен прокруткой, чтобы сохранить размер зон нажатия и читаемость.

## Техническая проверка

`npm run check` прошёл: форматирование, lint, typecheck, 61 тест, production build. Backend: Ruff и 11 тестов адаптера каталога. Полный backend-набор на локальном Python 3.14 не собирается из-за установленной версии SQLAlchemy. Браузерный проход с моками API: 34 состояния, 0 ошибок JavaScript, 0 случаев горизонтального переполнения. Проверены основная кнопка создания сигнала над активными карточками и переход в форму, поиск по каталогу занятий, пауза и возобновление повторяющегося поиска, возврат из подтверждения остановки, переключение компании без перехода на главную и обновление участников, добавление места, меню действий, движение индикатора и его отключение при `prefers-reduced-motion`. Проверка ждёт загрузки стилей и Max Sans; внешний MAX SDK заменён пустым мок-скриптом.
