# Безопасность и данные

## Личность и права

Backend проверяет подпись и срок MAX initData; переданный клиентом `user_id` не авторизует пользователя. Заголовок `X-Demo-User` допускается только при совместных `APP_ENV=development` и `ALLOW_DEMO_AUTH=true`; по умолчанию он отклоняется. Подписанный контекст чата и проверка доступа бота необходимы для привязки Компании к чату.

Маршруты проверяют владельца или членство в Компании. Координаты и адреса другого человека, точный бюджет, личные Сигналы/Автосигналы, причины Near и несовместимости, отказ и очередь ожидания не передаются другим клиентам. Скрытие поля на экране не заменяет ограничение API. До подтверждения состава возвращаются счётчики без имён; после — только разрешённые профили принятых участников. Личный минимум и прогресс условного участника доступны ему одному.

Сохранённая точка принадлежит пользователю и городу. Координаты получаются из реальной геолокации, не подставляются за пользователя; ответы API точек не содержат координат. Пользователь может редактировать/отменять Сигнал, приостанавливать/удалять Автосигнал, удалить неиспользуемое место и отменить участие до закрытия приёма. Полной политики автоматического удаления истории и общего удаления аккаунта MVP не заявляет.

## Секреты и эксплуатация

`.env` исключён из Git; `.env.example` содержит только пустые секреты и локальные значения. Рабочие токены, пароли и полные auth payload не должны попадать в репозиторий, презентацию общего доступа или логи. В production нужны собственные секреты и HTTPS. Данные проверки для организатора передаются в установленном им закрытом формате.

Ограничение частоты запросов не реализовано в приложении: защита публичного deployment от злоупотребления остаётся эксплуатационной задачей. Нельзя считать наличие авторизации заменой такой защиты. Проверка зависимостей и их лицензий входит в подготовку сдачи; закрытые библиотеки и частные API без разрешения запрещены кейсом.

Изменения приглашений защищены транзакциями и блокировками. Повтор того же завершённого действия идемпотентен, противоположное действие конфликтует. Порядок блокировок и ограничения доставки outbox описаны в [ARCHITECTURE.md](ARCHITECTURE.md).

## Происхождение и актуальность

В снимке плана сохраняются провайдер, ID и тип объекта, ссылка при наличии, время получения, исходная цена, разобранная цена, категория, адресные метаданные, предупреждение о часах и признак `is_demo`. Просто просмотренные объекты не создают строки каталога в PostgreSQL.

Следует различать:

- факт источника: название, опубликованный интервал, цена и адрес;
- расчёт приложения: расстояние по Haversine, совместимость, превышение бюджета, выбранный слот места;
- неопределённость: цена «от», непроверенный режим работы, отсутствующий факт;
- модель: явно помеченная демонстрационная запись.

Redis хранит только запрошенную выборку города/времени/категорий с TTL. Действующий кеш может использоваться без нового запроса, в том числе при ошибке провайдера. Истёкшие данные не становятся текущими, PostgreSQL не заменяет кеш каталога. Без пригодного кеша недоступность источника показывается честно.

Цена разбирается консервативно: недостоверное число остаётся отсутствующим. «От» — нижняя граница с предупреждением, неизвестная цена не удовлетворяет личному бюджету. Полный интервал события должен быть подтверждён источником и помещаться в доступность. У места с непроверенными часами есть предупреждение и ссылка для самостоятельной проверки.

## Демонстрационные данные

`POST /api/v1/development/seed-demo/{group_id}` создаёт явно помеченные модельные приглашения при подходящих Сигналах и доступен только в development. Он не проверяет KudaGo и доставку MAX. Модельные данные не подмешиваются автоматически при сбое провайдера и не выдаются за результаты исследования.

KudaGo — исходный внешний провайдер, а не государственный источник. Рекомендованные кейсом Культура.РФ, PRO.Культура.РФ, источники Минспорта, Путешествуем.рф, Добро.рф, Пушкинская карта и ФИАС не интегрированы. Подключение официальных или партнёрских источников — возможное продолжение после проверки качества и прав использования.
