# Проверка внешних зависимостей и ассетов

Это перечень для ручного подтверждения прав перед публичной сдачей, не юридическое заключение. Версии зафиксированы в `frontend/package-lock.json` и `backend/requirements.lock`; ниже указаны метаданные установленных пакетов, проверенные локально.

| Объект | Что видно в репозитории или metadata | Что подтвердить |
| --- | --- | --- |
| `@maxhub/max-ui` 0.5.0 | В package metadata указано `MIT` | Условия использования и атрибуции версии в итоговой сборке |
| `@fontsource-variable/unbounded` 5.3.0 | В package metadata указано `OFL-1.1` | Сохранение требуемых уведомлений для шрифта |
| `frontend/src/assets/fonts/Max_Sans_Regular.woff2`, `Max_Sans_Medium.woff2` | Файлы Max Sans включены в репозиторий; отдельного разрешения/лицензии рядом нет | **NEEDS_TEAM_INPUT:** происхождение файлов и право распространять их в репозитории и Mini App |
| `frontend/src/assets/figma-company/*.svg` | 13 SVG-файлов включены в код, источник прав в репозитории не указан | **NEEDS_TEAM_INPUT:** происхождение макета/иконок и право распространения |
| Backend `psycopg[binary]` 3.2.4 | У установленного пакета metadata сообщает `LGPLv3` | Применимые условия для способа распространения backend образа |
| Backend `fastapi` 0.115.8 | Поле License/License-Expression в установленной metadata не заполнено | Проверить сопровождающий license-файл пакета/релиза |
| Остальные прямые frontend/backend зависимости | Для проверенных локально прямых пакетов metadata указывает MIT, BSD-3-Clause или Apache-2.0; полный перечень версий в lockfiles | Проверить полное дерево зависимостей и требуемые уведомления перед публикацией |

В репозитории нет собственного `LICENSE`/`NOTICE` и нет отдельного файла разрешения для Max Sans и SVG. Решение о включении этих файлов в публичный артефакт принимает правообладатель/команда. Исторические QA-скриншоты и концепты удалены из текущего дерева; если репозиторий распространяется с полной Git-историей, её ассеты также требуют оценки.
