# Шаблон плана пилота

Пилот и пользовательское исследование в репозитории **не подтверждены**. Заполняйте этот шаблон только согласованными фактами; численные цели и результаты нельзя выводить из наличия технических метрик.

| Поле | Текущее состояние |
| --- | --- |
| Target segment | Небольшие компании друзей, уже общающиеся в мессенджере; точные критерии набора — `NEEDS_TEAM_INPUT` |
| Pilot city | `NEEDS_TEAM_INPUT`; выбор зависит от покрытия KudaGo/Geoapify |
| Acquisition channel | `NEEDS_TEAM_INPUT` |
| Required integrations | MAX bot/Mini App и HTTPS API; PostgreSQL; KudaGo; Geoapify при проверке обычных мест |
| Owner | `NEEDS_TEAM_INPUT` |
| Success metrics | Доля подходящих сигналов до `GATHERED`, `launch → first reaction/match/gathered`, число review-уведомлений и подтверждений; критерии успеха/знаменатель — `NEEDS_TEAM_INPUT` |
| Risks | Низкое покрытие источников, неизвестные цена/часы, отказы MAX/провайдера, недостаток активных участников |
| Next step | Утвердить город/сегмент и критерии, провести проверку источников, затем измерять реальные эпизоды; владелец и дата — `NEEDS_TEAM_INPUT` |

Ядро продукта при масштабировании: сигнал, выбор кандидатов, приватные реакции, совпадение, подтверждение, собранный план. По городу/контексту меняются покрытие провайдера, геоданные, соответствия таксономии, региональные источники и потенциальные партнёры. Следующий город без решения команды не зафиксирован. Определения измерений: [PRODUCT_METRICS.md](PRODUCT_METRICS.md).
